# Scatterplot Lab

An interactive classroom tool for Research Methods (Chapter 5: Reliability of Measurement).

- **Our class data:** test the Academic Habits Snapshot for test-retest, internal and interrater reliability, and criterion validity.
- **Playground:** add and drag dots to see how the correlation coefficient r changes.

Everything is in one file, `index.html`. No installs or build steps.

Made by Dr. Erica K. King.
